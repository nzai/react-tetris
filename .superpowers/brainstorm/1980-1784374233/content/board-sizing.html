20×20 棋盘如何适配屏幕？

当前格子 40×40px。20 列意味着棋盘宽度从 420px 翻倍到 840px。怎么处理？

A

缩小格子到 25px ⭐ 推荐

格子从 40px → 25px（含边距约 27px/格）。20 列棋盘约 540px 宽，整体容器约 620px——比现在的 500px 只宽了一点，手机竖屏缩放后仍然可用。代价是格子小了些，但俄罗斯方块不需要精细操作。

B

缩小格子到 30px

格子 30px（含边距约 32px/格）。20 列棋盘约 640px 宽，容器约 720px。折中方案——桌面端舒服，手机端缩放后偏小但能玩。

C

保持 40px，依赖缩放

格子不变，容器约 900px 宽。桌面端（1920px 宽）完全没问题。手机上靠 CSS scale 缩小，20 列在手机上会缩到约 0.4 倍——能玩但体验一般。

尺寸对比（同比例）

方案 A：25px 格子 → 容器 ~620px
方案 C：40px 格子 → 容器 ~900px
💡 提示：不管选哪种，单机模式（10×20）可以保留原来的 40px 格子，只有联机模式（20×20）才用缩小后的格子。两种模式各自独立布局。
