如何发现房间？（不输 IP）

浏览器无法扫描局域网。以下是绕过手动输入 IP 的实用方案：

A

📱 二维码扫码加入 ⭐ 最推荐

房主创建房间后，屏幕上显示一个二维码，内含 ws://192.168.1.5:3456 的完整连接地址。另一个玩家用手机扫一扫即可加入，零输入、零配置。二维码本身就是"发现"机制。

优点

  • 完全不需要知道 IP
  • 适合手机+PC 混合场景
  • 实现简单（qrcode 库 ≈ 5KB）

缺点

  • 两个手机之间扫码不太方便
  • 需要摄像头权限
B

🔢 房间号 + 轻量中继

需要一个极简中继服务器（几十行代码），部署在局域网内任意一台机器或公网。房主创建房间 → 得到 4 位房间号，客机输入房间号 → 中继服务器匹配双方 WebSocket 地址，后续直连。

优点

  • 输入 4 位数字即可
  • 两个手机也能方便配对
  • 可扩展到互联网联机

缺点

  • 需要额外部署中继服务
  • 中继挂了就配对不了
C

🔗 分享链接（手动兜底）

房主页面显示完整加入链接（如 http://192.168.1.5:3456/join），通过微信/短信/隔空投送发给对方。同时保留手动输 IP 作为兜底。

推荐策略：二维码为主 + 手动兜底
