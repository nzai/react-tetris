双人界面布局

12×20 棋盘（~512px 宽），需要展示两个玩家的 next 预览 + 共享分数。怎么排？

A

顶部信息栏并排 ⭐ 推荐

延续现有布局风格。顶部信息栏左右分区：玩家A（next + 消除行数）在左，共享分数居中，玩家B（next + 消除行数）在右。棋盘在下方。改动最小，一目了然。

B

左右侧边栏

棋盘居中，玩家A 信息在左侧竖直排列，玩家B 信息在右侧竖直排列。视觉对称，但容器会变宽（棋盘 512px + 两侧各 ~100px ≈ 700px+），手机端更局促。

C

上下分区

玩家A 信息在棋盘上方，玩家B 信息在棋盘下方。竖直方向拉长，不适合已有的 20 行高度。

方案 A 示意（延续现有风格）
